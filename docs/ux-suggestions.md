# 介面與使用體驗建議（2026-11-25，只是建議，尚未實作）

背景：使用者覺得目前的記錄板「有點令人混亂，反而讓跑團更麻煩」，希望更直覺、可視化（像拖動棋子決定陣營那樣）。

## 為什麼現在會覺得亂

1. **同一件事有兩個地方**：陣營在棋子上看，數值在列表裡改，新用戶不知道該操作哪一邊。
2. **一列塞太多東西**：先攻、先制、名字、HP、意志、狀態、行動計數、✓✗、展開……每個都可以點、同等顯眼，沒有主次。
3. **術語多又沒解釋**：先攻／先制／行動計數／✓✗／回合／輪，「下一回合」和「下一輪」名字太像。
4. **展開的詳細資料把頁面撐長**：點一下整頁往下推，看不到棋子，捲動位置也跳來跳去。
5. **最常用的操作藏得太深**：加異常狀態、升降能力要「展開 → 找區塊 → 選單 → 加入」，至少 4 次點擊。
6. **有隱藏功能**：HP 欄可以輸入 `-3` 增減，但沒有任何提示。
7. **關鍵按鈕會捲出畫面**：「下一回合／下一輪」在戰場圖下面，列表一長就要上下捲動找。
8. **固定格子雜訊多**：戰場圖永遠有 6 個空選單，大多數時候都是空的。
9. **加人太重**：「新增參戰者」是規則站完整的產生器面板，野生遭遇要點很多次。
10. **沒有回饋**：改了 HP、換了人，畫面沒有任何提示，不確定有沒有按到。
11. **手機不友善**：戰場圖最小寬度 900px 要橫向捲動，手指拖棋子也不順。

## 建議的方向

### A. 版面改成「戰場圖＋側邊面板＋固定底欄」
```
┌─────────────────────────────────────────────┬──────────────┐
│ [行動順序條] ▶皮卡丘 → 小火龍 → 巨沼怪 …（可拖動重排） │ 選取的角色     │
├─────────────────────────────────────────────┤ 皮卡丘        │
│                                             │ HP ▓▓▓░ 6/8  │
│            戰場圖（主角）                      │ 狀態 [麻痺]   │
│       棋子上直接看到 HP、狀態、行動點            │ 能力 力量-1   │
│                                             │ 招式 一行一招  │
├─────────────────────────────────────────────┴──────────────┤
│ 第 3 輪　輪到：皮卡丘　 [行動了 ✓ 換下一位]  [保留 ✗ 換下一位]  [結束本輪] │
└──────────────────────────────────────────────────────────────┘
```
- 列表縮成「行動順序條」，只負責排順序與看輪到誰。
- 展開的詳細資料搬到右邊抽屜，開關不會推擠版面。
- 底欄固定在畫面下方，按鈕永遠找得到。

### B. 讓棋子成為主要的操作面
- 棋子上直接看得到：HP 條、狀態小圖示、行動點（5 個小點，自動點亮）。
- **點血條**彈出快速加減：−5 −3 −1 ＋1 ＋3 ＋5 ＋輸入框，並跳出浮動數字（例如 −3）。
- **點棋子**彈出圓形選單：HP／狀態／能力／行動／更多。
- 狀態做成圖示列，一點就加或解除；灼傷多級用點擊循環。
- **把棋子拖到另一個棋子上**＝指定傷害目標，直接顯示該招的骰池與相剋，取代「傷害目標」下拉。
- 條目卡已經能拖到棋子上；也可以做「把狀態圖示拖到棋子上」。

### C. 回合流程簡化
- 目前輪到的角色，底欄兩顆大按鈕：**「行動了 ✓ 換下一位」**、**「保留 ✗ 換下一位」**，一次完成「標記＋推進」，不再有獨立的 ✓✗ 欄。
- 行動計數改成棋子上的 5 個小點，按「行動了」自動點亮，手動點一下可修正。
- 改成白話：「下一回合」→「換下一位」，「下一輪」→「結束本輪」。
- 先攻輸入放在順序條的頭像下面，輸入後自動排序（可關），拖動可覆蓋。「先制」預設隱藏，需要時才用「＋先制」叫出來。

### D. 資訊分層，預設只看最重要的
- 預設只顯示：誰、HP、狀態。意志、能力升降、備註都放進右邊抽屜。
- 招式預設一行一招：`招式名 ｜ 命中 9 ｜ 傷害 8`，點開才看效果；本輪已用的灰掉並排到後面。

### E. 條目更輕
- 固定格子預設收成一排圖示（☀ 天氣、⚡ 場地、🛡 力場、⚠ 危害）；空的不顯示選單，點圖示才展開。
- 自訂條目：在戰場圖空白處點一下就能新增，不必先找按鈕。

### F. 加人更快
- 一個搜尋框：輸入物種名按 Enter 加入，可加「× N 隻」。
- 「最近用過」與「遭遇範本」（備團 ①②⑤）：存好一組野生寶可夢，之後一鍵放上場。
- 玩家隊伍（pokepast／JSON）一鍵匯入全隊，直接放到綠區。
- 新角色預設放到你最後使用的那一側。

### G. 新手引導與說明
- 第一次打開顯示三步驟浮層：加人 → 拖到陣營 → 按「換下一位」。
- 空狀態畫面直接放大按鈕：「＋ 新增參戰者」、「匯入隊伍」。
- 專有名詞加滑鼠提示（先攻、先制、行動計數）；右上角放「？」說明。

### H. 回饋與安全
- 數值變動時跳浮動數字、輪到誰時短暫提示、新的一輪開頭跳橫幅。
- 「復原」按鈕寫出最近一步，例如「復原：皮卡丘 HP 9→6」。

### I. 小螢幕
- 手機自動切成「清單模式」：依側分組的卡片，用「移到…」選單取代拖動。
- 平板保留戰場圖，但棋子與按鈕加大。

### J. 鍵盤與觸控
- 快捷鍵：`N` 換下一位、`Shift+N` 結束本輪、`Z` 復原。
- 點擊目標至少 40px。

### K. 視覺
- 少字多圖示（狀態、屬性用圖示）；顏色只用在「陣營」與「警示」。

## 做的順序

1. **小改動、高回報**：固定底欄兩顆大按鈕、合併 ✓✗ 與換下一位、按鈕改白話、點血條快速加減、條目格子收合、預設隱藏先制與意志欄。
2. **中等**：右側抽屜取代展開列、行動順序條、棋子上的行動點與狀態圖示、快速新增（搜尋＋範本）。
3. **大**：棋子圓形選單、拖棋子到棋子上指定目標、手機清單模式、新手引導。

## 如果只做三件事

1. **固定底欄兩顆大按鈕**，並把標記與推進合併。
2. **右側抽屜取代展開列**。
3. **在棋子上直接看 HP／狀態／行動點**，把列表縮成行動順序條。

這三件直接解決「兩個地方操作」與「按鈕找不到」這兩個最大的混亂來源。

## 驗證方式（建議）

找博愛這類實際帶團的 GM，拿一場假戰鬥（3 對 3、含兩個異常狀態與一個天氣）讓他不看說明操作 10 分鐘，記下他停頓或問「這是什麼」的地方，比任何設計討論都準。
